# first-pr-practice

Practice repo for learning the GitHub PR workflow.

## About

This repository exists so I can practice the full pull request flow: creating a
branch, committing a change, pushing it, and opening a PR on GitHub.

## Workflow

1. Create a branch for your change
2. Commit your edits
3. Push the branch
4. Open a pull request and review the diff
5. Merge once it looks good
